# Audio Assets Directory

This directory contains default MP3 audio files for the Masjid Display application:

- `adzan.mp3`: Default Adzan call to prayer audio.
- `murottal_kahfi.mp3`: Pre-Adzan Al-Qur'an Murottal recitation audio.
- `dzikir_pagi.mp3`: Post-Subuh Dzikir Pagi audio recitation.
- `dzikir_petang.mp3`: Post-Ashar Dzikir Petang audio recitation.

Mosque administrators can also override audio tracks with custom remote URLs via the Web Admin Dashboard.
